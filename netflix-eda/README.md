# Netflix Data Analysis Project

## Overview
This project analyzes Netflix Movies and TV Shows dataset to uncover trends in content distribution, growth patterns, and user content preferences.

## Objectives
- Analyze Netflix content trends over time
- Identify top content-producing countries
- Understand distribution of Movies vs TV Shows
- Explore popular genres and durations

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Key Insights

- Movies dominate Netflix content library
- USA is the largest content producer
- Netflix saw major growth after 2016
- Dramas and International Movies are most common genres
- Most movies are 90–120 minutes long and TV Shows 1-2 seasons

## Exploratory Data Analysis
Includes:
- Content type distribution
- Country-wise content analysis
- Yearly content growth trends
- Genre analysis
- Duration analysis
- Release year analysis
- Rating Analysis
